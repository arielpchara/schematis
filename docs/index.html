Welcome

schematis is a zero-dependency functional JSON validator. Types and rules are functions. Bind keys with map. A schema call returns a check object, not { ok, value }.

Validate at the edge

Keep schemas as plain functions and call them where data enters your program. Read the result with isValid, assert, getParsed, and getErrors.

Installation

Node LTS (>=24). The package is ESM.

npm install schematis

Quick example

Import from schematis, or from schematis/types, schematis/rules, and schematis/tool.

Example (Object schema)

import { map } from 'schematis/tool'
import { isObject, isString, isNumber } from 'schematis/types'
import { hasMin } from 'schematis/rules'

const user = isObject(
  map('id', isString()),
  map('age', isNumber(hasMin(0))),
)

const check = user({ id: '42', age: 35 })
check.isValid()
check.getParsed()

How it fits

  • Types build schemas: isString, isObject, isUnion.
  • Rules constrain values: hasMin, isEmail.
  • Tools compose schemas: map, transform, strict.
  • Core is the check object and the pipeline.

undefined fails the type until optional(schema). Unknown object keys are dropped from getParsed() unless you wrap with strict().
