Core

Internals in src/core. Not a public export path. Calling a schema with a value returns a check object.

A check, not a result bag

Keep the public method names: isValid, assert, getParsed, getErrors.

isValid

Returns true when there are no issues.

Example (Pass and fail)

isString()('ok').isValid()
isNumber()('no').isValid()

assert

Throws Error if invalid. The message is one path: message line per issue.

Example (Throw on invalid)

isString()(undefined).assert()

getParsed

Returns the parsed value even when invalid. transform only converts after the input schema passes.

Example (Read parsed output)

isObject(map('id', isString()))({ id: '1', extra: 2 }).getParsed()

getErrors

Public errors are { path, message } with dotted paths (address.place, tags.0).

Example (Dotted path)

isObject(map('tags', isArray(isString())))({ tags: [1] }).getErrors()
// [{ path: 'tags.0', message: '...' }]

Pipeline

defineType runs in this order:

  1. undefined → one required issue; stop.
  2. Type guard fails → one type issue; stop.
  3. Run rules; if any fail, return them (parsed value is still the input).

transform wraps a schema; it is not a defineType argument.
